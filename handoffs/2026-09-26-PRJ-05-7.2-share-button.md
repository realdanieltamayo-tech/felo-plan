## Flow
Felo (tool felo_request_share: project, days 1-30 default 7, why) -> felo_shares row 'pending' (one per project)
-> phone alert (ntfy, /root/felo-v2-notify.py on CT100, opens /share) + Waiting page item
-> Daniel taps Share on /share (sidebar "Shares") -> 'approved'
-> Proxmox host watcher /usr/local/sbin/felo-share-watch (cron /etc/cron.d/felo-share-watch, every minute,
   log /var/log/felo-share-watch.log; repo copy ops/felo-share-watch.py) runs on CT101 /usr/local/sbin/felo-share-make
   -> frozen copy in /srv/felo-shares/s/<random id>/ (pages/styles/scripts/images/fonts only) -> 'live' + url + expires_at
-> Felo reads the link with felo_shares and gives it to Daniel (never emails the client).
Turn off now -> 'off_requested' -> watcher runs felo-share-remove -> 'off'. Past end -> 'expired'; CT101 hourly
felo-share-expire deletes the copy.
