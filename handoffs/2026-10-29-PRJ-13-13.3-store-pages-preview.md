# PRJ-13 13.3 — Store pages + cart (PREVIEW), 2026-10-29

Built on core in /data/sites/zubaloop (the zubaloop.com company site). Live site NOT changed yet.

## What exists
- static/store/catalog.json — the 8 products (slug, group builds/cards, name, tag, tagline, desc, price, images, specs,
  illustration flag, photo_note). Prices = 13.1 decisions (Core 2299, Pro 3699, Max 8499, 5090 5599, 5080 1699, 5070 949,
  4090 used 2599, 4080 used 1149). Edit this file to change products/prices, then rebuild.
- store_build.py (called from build.py) — writes DIST/store/index.html, <slug>.html, cart.html. Products without images get a
  drawn card outline. Every product page: "Want real photos or more details? Email us" (mailto info@zubaloop.com, product in
  subject); illustration note on AI images; "Current warehouse stock." on the 5090 photos; NVIDIA trademark / not-affiliated line.
- static/store.js — cart in localStorage (felo-store-cart: slug + qty only; names/prices always from catalog.json), max 5 per
  product, nav cart badge, toast, photo thumbnails, cart page. Checkout = "Email this order" (mailto with the cart, subtotal,
  and blanks for name / address / phone) until 13.4.
- template.html: Store menu (Gaming PCs, Graphics cards, popular items, cart), cart icon, Store in mobile menu + footer, store.js.
- styles.css: small STORE block at the end (reuses the old shop grid, product page, buy bar, cart styles).
- build.py: SITE_DIST env var builds elsewhere; "store" nav key. Backups: *.bak-store-20261029.
- Images in static/store/ (unused originals moved to store-originals/, not published).

## Preview
- http://100.87.6.99:8099/store/ (Tailscale only): container zubaloop-preview, files /data/sites/zubaloop/preview-dist,
  config preview-nginx.conf. Rebuild: cd /data/sites/zubaloop && sudo -u daniel SITE_DIST=/data/sites/zubaloop/preview-dist python3 build.py
- Tested in headless Chromium (playwright image on core), desktop 1366 and phone 390: pages render, add to cart, quantities,
  remove, totals ($5,599 + 2 x $3,699 = $12,997), mailto order link; no console errors.
