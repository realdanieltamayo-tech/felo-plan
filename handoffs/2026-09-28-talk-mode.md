# Handoff — Talk mode: real voice conversation in Felo HQ (built 2026-09-28, branch talk-mode)

Daniel (2026-09-28): "app downloaded but I can't still talk to it like a normal person with voice". Cause: the mic used
the browser's one-shot SpeechRecognition (fails on iPhone/installed app; one sentence per tap).

- hq.html talk mode: mic tap starts a loop: listen -> (browser SR on computer/Android; on iPhone/others MediaRecorder with
  voice-activity detection: noise-floor calibration 400 ms, speech > 120 ms starts, 1.1 s silence or 30 s ends, < 0.6 s
  ignored) -> /api/hq/listen -> submit(voice) -> speak(reply, talkResume, force) -> listen again. Tap while speaking =
  interrupt; tap otherwise or say stop/bye/para/adiós/listo = end. iPhone: one reused Audio element unlocked with a silent
  WAV on the first tap. Old stopMic/startLevels code removed.
- hq-routes.js: VOICE_HINT prefix (1-3 short spoken sentences) when body.voice === true.
- lib/voice.js mountListen: POST /api/hq/listen (express.raw 8 MB) -> http://felo-voice:8080/listen; gate allows it.
- voice/ sidecar (rebuilt): python:3.12-slim, edge-tts + faster-whisper base int8 (model baked into the image, HF offline),
  user felovoice (group "voice" exists in Debian), --memory 1500m, FELO_STT_THREADS=8, /speak + /listen + /health.
  Timing: ~5 s to understand a 5 s sentence (Xeon X5670, no AVX2); speak ~0.7 s.
- Box 100 CPU: pct set 100 -cores 8 (was 2). Host: 24 threads, low load.
- Tests: 375 pass.
