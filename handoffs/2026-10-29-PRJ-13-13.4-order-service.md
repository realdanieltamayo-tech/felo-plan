# PRJ-13 13.4 — Store order service, 2026-10-29

Decisions (Daniel): free US shipping; Stripe Tax for sales tax.

## felo-store (core)
- Code + compose: /data/services/felo-store (app.py, test_app.py, Dockerfile, docker-compose.yml; local git repo; .env NOT in git).
  `cd /data/services/felo-store && docker compose up -d --build`. Flask + gunicorn + stripe 10.12.0, read-only container, user 10001.
- Orders: /data/store-orders/FS-YYMMDD-XXXX.json + _events.jsonl (seq log for Felo HQ). Catalog: mounted read-only from
  /data/sites/zubaloop/static/store/catalog.json, so the service and the pages always use the same prices.
- Public via the company nginx: /api/store/ -> felo-store:8080 on docker network felo-store (felostudio-web joined it; felo-web
  compose backup docker-compose.yml.bak-store-20261029; nginx.conf backup nginx.conf.bak-api-store-20261029). /api/store/admin/ -> 404 publicly.
- Admin API (for 13.5 Felo HQ dashboard): Tailscale 100.87.6.99:8086, Bearer ADMIN_TOKEN (random, in .env; give it to Felo HQ
  via its own settings script, never print it). GET /api/store/admin/orders?status=open|all|<s>, GET .../orders/<id>,
  POST .../orders/<id>/status {status, carrier, tracking, note} (paid->processing/shipped/canceled/refunded, processing->shipped..,
  shipped needs carrier + tracking), GET /api/store/admin/events?after=<seq>. "refunded" only records it; the refund itself is done in Stripe.
- Checkout: POST /api/store/checkout {items:[{slug,qty}]} (Origin must be zubaloop.com, 12/min/IP, max 5 per product, 10 lines),
  prices from the catalog, Stripe Checkout: card, US shipping address, phone, free shipping, automatic_tax = STORE_STRIPE_TAX,
  success -> /store/thanks.html?session_id=..., cancel -> /store/cart.html. Webhook POST /api/store/stripe-webhook (signature checked):
  checkout.session.completed / async_payment_succeeded -> paid (+ customer, shipping address, tax, total), expired / async failed.
  Handles both shipping_details and collected_information.shipping_details (Stripe API versions differ).
- Keys: `sudo felo-store-set-stripe` on core (hidden typing): secret key, webhook signing secret, Stripe Tax on/off; restarts and prints /api/store/health.
- Tests: 7 unit tests (fake Stripe create, real webhook signature check) pass:
  docker run --rm -u 0 -v $PWD/test_app.py:/app/test_app.py:ro felo-store:latest python -m unittest test_app
