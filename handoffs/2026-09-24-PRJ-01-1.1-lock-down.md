## Lessons (for every future session)
- **Never print settings files**, not even "masked" — masking with sed failed twice today. Use hash comparisons or key names only.
- Write multi-line scripts to a file and `pct push` them; inline quoting broke several times.
- A file can mix CRLF and LF (`app/hq-routes.js`) — edit with `open(p, newline="")`.
- The host copy and repo copy of ops scripts drifted once (deployer missing the intake restart). After any ops change: `cmp /root/<script> /root/felo-codex-preview/ops/<script>`.
- Core is on Wi-Fi and dropped out 15:30–~16:30 UTC; Daniel will move it to ethernet.
